Publicarlo en la web (acceso desde cualquier dispositivo)

Este archivo es autocontenido: no necesita servidor ni dependencias. Para tenerlo en una URL propia, gratis:

  1. Crea un repo público en tu GitHub, por ejemplo fde-roadmap.
  2. Sube este archivo con el nombre index.html en la raíz.
  3. Settings → Pages → Source: "Deploy from a branch" → Branch: main → Save.
  4. En 1-3 minutos queda en kenderb.github.io/fde-roadmap. Agrégalo a la pantalla de inicio del celular.

Nota honesta sobre el guardado: el progreso se guarda solo, en el navegador de cada dispositivo. No se sincroniza por sí mismo entre tu celular y tu computador, porque eso requeriría un backend. Por eso están los botones de exportar e importar: un copiar-pegar cuando quieras alinearlos.
